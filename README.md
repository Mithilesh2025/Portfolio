# Mithilesh R - Personal Portfolio

A modern, dynamic, and fully responsive personal portfolio website showcasing my academic projects, technical skills, and educational background. Designed with a vibrant dark theme, glassmorphism UI, and smooth scroll animations.

## 🚀 Live Demo

**[View Portfolio Live](https://mithilesh2025.github.io/Portfolio/)**

## ✨ Features

- **Dynamic Tree Timeline:** A visually engaging, alternating vertical timeline for the education section.
- **Glassmorphism UI:** Modern translucent cards with backdrop blur and colorful glowing hover effects.
- **Scroll Animations:** Smooth entry animations (fade, zoom, slide) powered by AOS (Animate On Scroll).
- **Animated Backgrounds:** Drifting CSS gradient blobs and pulse effects that bring the site to life.
- **Fully Responsive:** Beautifully adapts to mobile, tablet, and desktop screens without breaking the layout.

## 🛠️ Tech Stack

- **HTML5:** Semantic HTML structure.
- **Tailwind CSS (via CDN):** Utility-first CSS framework for rapid, custom styling and responsive design.
- **AOS Library:** For scroll-triggered animations.
- **FontAwesome:** For scalable vector icons.
- **Google Fonts:** Utilizing the 'Outfit' font family for a sleek, modern aesthetic.

## 💻 Local Setup

Since this is a static single-page application, no build tools, frameworks, or package managers are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/Mithilesh2025/Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Portfolio
   ```
3. Open `index.html` directly in your favorite web browser (or use VS Code Live Server).
